# Seoul Bike Sharing Demand Analysis 
## By Song Vu Nguyen
I will use my final project in DATA_SCI 7020 class, using the Seoul Bike Sharing Demand dataset from the UCI Machine Learning Repository. I will do data cleaning and format it appropriately for machine learning. For the cloud, I will use Kubernetes for machine learning tasks. I will request 1 CPU, 1 GPU to start with, and 1GB of persistent volume to store results.
Modern cities with a large population come with a large number of cars, causing daily traffic jams and pollution that harms the environment. Recently, companies have provided bike-sharing services in big cities as a solution. However, there is a limited number of bikes, so forecasting demand throughout the day would help provide the optimal number of bikes. My goal is to examine the effects of different factors on the number of bikes rented and make predictions to meet people's demand.
For an analytical approach, I will do EDA to test the correlations between different variables and the number of bikes rented. I will then use feature ranking to pick the most significant variables. For machine learning, I plan to build models using different algorithms such as Random Forest, Linear Regression, and Poisson Regression. All code will be implemented in the Mizzou Jupyter Notebook environment, with machine learning tasks run using Kubernetes pods/jobs through the Nautilus cloud platform. Model success will be measured using prediction errors through metrics such as Mean Squared Error.
Through this project, I hope to discover what factors impact the number of bikes rented and build an ML model that can predict bike-sharing demand as accurately as possible. However, with limited cloud resources, I anticipate limiting the number of parameter-tweaking jobs my model can run to reach optimal solutions.
